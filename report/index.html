Dust in the bearings

What this result does and does not establish

Small sample // strong local effect

This run evaluates 10,230 predicted tokens—about 0.095% of the paper's 10.8M-token PG-19 evaluation. Its 13.676% reduction is close to the paper's 14.41%, but the two-book sample is not a substitute for the full corpus.

Pilot and stopping rule

The initial two-window pilot slightly worsened perplexity by 0.396%. The sample was extended exactly once by a content-blind rule to five windows from each same book, then stopped regardless of direction. The eight added windows alone improve by 16.874%.

Mask failure caught and rejected

An early diagnostic incorrectly gave sliding layers the full-attention mask, inflating pilot baseline PPL to 75.636. An official-forward equivalence check exposed it. Native 512-token sliding masks restore pilot baseline PPL to 19.201; only corrected numbers appear in final results.

Paper ambiguities

The paper does not pin software, model, tokenizer, or data revisions, dtype, or device. It introduces the 1B ten-token ramp but does not explicitly state whether Table 1 includes it. This reproduction pins everything and includes the ramp as the closest reading of the final method.

Uncertainty and performance claims

A descriptive paired-window bootstrap gives 7.69%–19.55%, but windows within a book are dependent, so this is sensitivity evidence rather than a population confidence interval. The paper's near-zero generation-latency claim is not tested: this artifact measures serial prefill only.

Next work order // deliberately not run

Hold every mechanism setting fixed. Move to eight unseen PG-19 books.

Take the first five complete windows from the next eight test records. That single test would show whether the effect survives broader document variation without changing source, destination, α, β, normalization, ramp, or recurrence count.
